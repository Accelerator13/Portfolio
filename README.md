---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando a stack **React + TypeScript**, focando em produtividade e tipagem forte:

*   **Frontend:** React.js, Tailwind CSS (Design Responsivo)
*   **Linguagem:** TypeScript (Segurança de tipos)
*   **Ferramentas:** Vite, Lucide Icons (Ícones)
*   **Deploy:** Netlify / Vercel

---

## 🧠 Desafios e Aprendizados

Neste projeto, foquei em resolver dois problemas principais:
1.  **Arquitetura Escalável:** Organizei o código em componentes menores e reutilizáveis, facilitando a manutenção.
2.  **Performance:** Otimizei o carregamento de ativos e utilizei classes utilitárias do Tailwind para garantir um CSS enxuto.
